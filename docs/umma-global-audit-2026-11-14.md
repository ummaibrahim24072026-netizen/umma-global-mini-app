Подготовлен выпуск только Edge Function `cafe-kitchen`. Для него не нужны изменения схемы или повторная публикация GitHub Pages. Перед выпуском прогнать сценарий доставки и самовывоза в staging с тестовыми ролями и отдельным ботом. После подтверждения владельца проверить доступность нового заказа на экране кухни и кассы, повтор оплаты, переход статусов и завершение доставки.

Для отката сохранены семь файлов действующей `cafe-kitchen` v40 и проверено их совпадение с исходным коммитом. В staging требуется подтвердить восстановление этого пакета с действующим `verify_jwt=false` и внутренней проверкой Telegram или сессии сотрудника. База и GitHub Pages для этого отката изменений не требуют. Откат через повторное развёртывание пакета пока не выполнен.
